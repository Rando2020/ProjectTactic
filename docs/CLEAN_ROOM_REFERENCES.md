# Clean-Room References

This project can study genre structure without copying protected content.

## What We Can Learn

From Final Fantasy Tactics-style design:

- Charge-based turn pressure.
- Jobs as data-defined ability bundles.
- Height and terrain as tactical constraints.
- Clear battle objectives.

From Triangle Strategy-style design:

- Readable elevation advantages.
- Positional pressure.
- Follow-up and formation incentives.
- Story battles with bespoke layouts.

From Divinity: Original Sin 2-style design:

- Action economy that makes each turn a resource puzzle.
- Environmental surfaces.
- Elemental or terrain reactions.
- Status-driven encounter variety.

## What We Should Not Copy

- Names, maps, scripts, dialogue, source, tables, exact formulas, art, sound, UI skins, or scenario content from those games.

## Project Tactics Interpretation

Project Tactics should use original formulas, data, art, story, characters, jobs, and encounters. The references should only inform broad design questions like “what does the player need to understand at a glance?” and “what makes a tile tactically meaningful?”
