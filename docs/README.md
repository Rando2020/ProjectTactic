# Documentation Hub

This folder is the design and production brain for ProjectTactic / The Appointed.

## Current pathways

- `lore/` - canon, cosmology, factions, places, terminology, and the Recurrence narrative bible.
- `characters/` - human-scale character arcs, cast tensions, biographies, and story roles.
- `design/` - game design, narrative integration, UI direction, jobs, and content design.
- `systems/` - production-facing system ownership and implementation handoffs.
- `architecture/` - technical architecture and source-of-truth decisions.
- `production/` - roadmap, backlog notes, testing, release, and workspace guidance.
- `archive/` - retired documentation kept for historical context only.

## Story entry points

Read these in order when working on narrative:

1. `lore/recurrence-narrative-bible.md`
2. `design/recurrence-run-integration.md`
3. `systems/recurrence-story-runtime.md`
4. `characters/history-cycle-cast.md`

The first three define the deeper authorial truth and runtime delivery. The character guide defines the Act I political layer players encounter before the cosmology is understood.

## Rule

When a gameplay or story idea becomes runtime code, update the matching documentation in the same pull request.

Archived documents are references, not source of truth.
