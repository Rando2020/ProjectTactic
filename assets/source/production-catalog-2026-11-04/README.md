# Production catalog and candidate archive

This is a source/review archive, **not a game-ready art pack**. It does not change a scene, loader, runtime manifest, or deployed game.

- [Design](PROJECTTACTIC-ASSET-DESIGN.md): 63 asset families and acceptance contracts.
- [Catalog](production-catalog.json) / [CSV](production-catalog.csv): production backlog, not an engine manifest.
- [Candidate register](candidate-register.json): 1 existing approved identity reference, 3 unapproved candidates and 5 studies, with relative PNG paths and SHA-256 hashes.
- [Historical combat inventory](verified-reusable-frames.csv): 76 PNG frames audited in the v11 archive; these older frames are not copied here and this inventory is not a current-main runtime claim.

## Readiness
Zane rear candidates have different scale/foot anchors, costume and pose drift; the opposite front view is missing. Cultist studies fail handedness consistency. Haste and stone are exploratory. The pillar has genuine alpha but no tested footprint/occlusion. Nothing here should silently replace accepted art.

## Provenance and rights
The candidate and study PNGs were generated with OpenAI image generation on November 4, 2026 for ProjectTactic. Zane candidates used the existing approved illustrated front as identity reference and existing model renders as pose guides; the pillar used the existing Blooming courtyard as a style reference. The front reference is an unchanged existing project asset (SHA-256 recorded in the register). Generation and source provenance are not a new blanket license grant. No third-party fonts, models, purchased packs, skills or executable packages are added. Existing repository licensing is unchanged.

## Validation
JSON/CSV structure, family/register counts, PNG integrity/dimensions, image hashes, relative file paths, secret/private-metadata scan, and source-only file scope were checked. No new engine, browser, animation, or visual-acceptance claim is made.
