# Authored melee presentation

User-supplied Golden Slash and Impact sheets, retained unchanged in originals/.
Four lossless padded RGBA frames per effect; manifest records source hashes and extraction rectangles. No original pixels were discarded. Original sources are excluded from runtime exports. Haste/Delay remain deferred and are not included.

These cosmetics play only after the existing ActionLifecycle contact/outcome event for isolated-demo basic melee attacks. They never apply damage, spend resources, or change turns. Fire keeps its own impact. Missing frame resources retain the procedural fallback.

The slash pivot in the preparation kit is the nominal cell center, NOT a hand/socket. Runtime uses the projected attacker-to-target direction and a small forward contact-space offset, not a falsely attached hand anchor. Frame timing is cosmetic and independent of combat recovery.
