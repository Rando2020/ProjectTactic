# UI UX Quality

## When to use
Use for HUD, menus, interaction states, responsive layouts and accessibility.

## Procedure
1. Define the player task and evidence from actual scenes/screenshots.
2. Inspect HUD hierarchy, legibility at play distance, keyboard/gamepad focus, touch sizing where relevant, color contrast, reduced motion, latency, empty/loading/error states.
3. Check layouts against real in-engine captures at target resolutions.
4. Report verified observations separately from design proposals.

## Gate
- Preserve repository behavior and project constraints.
- State source of evidence and checks actually run.
- No merge, public release, or live-demo change without explicit authorization.
