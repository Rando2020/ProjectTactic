# Taste Review

## When to use
Use for character presentation, combat readability, animation and interface polish.

## Procedure
1. Identify visual intent, target audience, comparable reference and design constraints.
2. Judge hierarchy, silhouette, balance, typography, composition, transition pacing and cohesive art direction.
3. Identify the three most consequential mismatches using screenshots or clips.
4. Propose concrete asset/layout changes and visual acceptance criteria; do not call subjective judgment objective proof.

## Gate
- Preserve repository behavior and project constraints.
- State source of evidence and checks actually run.
- No merge, public release, or live-demo change without explicit authorization.
