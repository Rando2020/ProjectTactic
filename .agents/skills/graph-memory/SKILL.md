# Graph Memory

## When to use
Use only when relationships outperform simpler documented state.

## Procedure
1. Define entities, typed relations, provenance and update lifecycle.
2. Compare graph retrieval with a simple document/index baseline.
3. Specify staleness, identity resolution, privacy, deletion and access controls.
4. Test relationship queries and reject unnecessary graph infrastructure.

## Gate
- Preserve repository behavior and project constraints.
- State source of evidence and checks actually run.
- No merge, public release, or live-demo change without explicit authorization.
