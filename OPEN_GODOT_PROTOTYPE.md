# Open the Godot Prototype

The Godot project is here:

`C:\Users\jojo3\Project-Tactics\godot\project.godot`

To open it:

1. Open Godot 4.x.
2. Choose **Import**.
3. Select `C:\Users\jojo3\Project-Tactics\godot\project.godot`.
4. Run the project.

If Godot is available on your PATH, you can also run:

`tools\open_godot_prototype.bat`
