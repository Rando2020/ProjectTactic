# Act 1 3D grid bridge

Start with [NOVA-HANDOFF.md](NOVA-HANDOFF.md) for integration, scale conversion and limitations.

![Environment prototype](review/environment.png)

Six reference-informed GLBs plus editable Blender source and a standalone Godot grid preview. This prototype demonstrates how the user's illustrated tiles can inform 3D terrain while gameplay stays controlled by a logical grid. It is an integration sample, not final target-quality art.
